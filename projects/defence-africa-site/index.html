01 What this system is

A consultancy that sells analysis lives or dies on how it presents itself. Defence Africa’s audience — investment managers, corporate security directors, policy makers — visits the site to answer one question: can these people be trusted with serious questions? The site had to make the answer obvious in the first ten seconds.

02 What I built

A geopolitical-authority identity. Deep navy and warm gold, Playfair Display headlines over Inter body text, asymmetric layouts with deliberate breathing room — the visual register of a serious briefing, not a startup landing page.

Services showcase. The three core service offerings, presented as interactive cards with purposeful hover transitions — enough motion to feel alive, none to feel decorative.

The Briefing Room. A featured-analysis hub — the section that turns one-time visitors into returning readers, and readers into inquiries.

Lead generation. Multiple contact methods plus an inquiry form, all reachable from every section on a fully responsive layout that holds up on phones as well as desktops.

03 Where it stands

The site is live at gadda00.github.io/defence-africa-site — verified 11 Nov 2026 — with the full source public on GitHub. It ships as a static Vite build on GitHub Pages, which keeps hosting at zero marginal cost for a consultancy site of this scope.
